## 🔬 Evaluation research

### [Counter-Evidence-RAG](https://github.com/bksampadi/Counter-Evidence-RAG)

**What happens when answer-changing evidence exists, but never reaches the generator?**

Across six controlled claims:

### **6/6 correct → 0/6 correct**

while context-anchored evaluation remained strongly positive.

The project includes frozen benchmarks, independent generator replication, external metric validation, restoration experiments, and reproducible evaluation scripts.

`LLM Evaluation` · `RAG` · `RAGAS` · `Reproducibility`

**→ [Read the technical report](https://github.com/bksampadi/Counter-Evidence-RAG/blob/main/paper/technical_report.md)**
